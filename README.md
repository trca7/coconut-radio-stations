# Coconut Radio station list

The station list and station logos for the **Coconut Radio** iPhone and CarPlay app.
The app downloads `catalog.json` from this repository, so stations can be added or fixed
without an app update.

- `catalog.json` — categories and stations (name, stream address, genre, location).
- `logos/` — station logos, shown in the app's lists. Logos belong to their stations.

This file is generated; please don't edit it by hand. To suggest a station, or to ask for
a stream or logo to be removed, write to coconutradioios@gmail.com.
